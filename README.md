I'm a first-year Software Engineering student at **FIAP** with a technical background in **Mechatronics** (ETEC). My focus is on bridging hardware and software — particularly through **computer vision, machine learning, and backend development**.

Currently building **VisuAll**, a real-time Brazilian Sign Language (Libras) recognition system using MediaPipe and MLP classifiers, as part of FIAP's 2026 Challenge program.

---

### Featured Project

**[VisuAll — Real-Time Libras Recognition](https://github.com/Juanduarte050508/VisuAll)**
Computer vision system that recognizes the Brazilian Sign Language alphabet in real time. Routes detected hand landmarks between two specialized MLPs (static vs dynamic letters) based on motion heuristics. Python backend over WebSocket, browser-based frontend.
`Python` · `MediaPipe` · `scikit-learn` · `WebSocket` · `OpenCV`
