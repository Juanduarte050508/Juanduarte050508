### 🤟 VisuAll — Libras Recognition
> Real-time Brazilian Sign Language (Libras) recognition system.

AI system that recognizes both the **alphabet** (static & dynamic MLP models)
and **body signs** (MediaPipe Holistic + LSTM). Unified backend/frontend with
adaptive facial calibration and a token-list phrase architecture.

`Python` · `TensorFlow/Keras` · `MediaPipe` · `scikit-learn` · `WebSocket`

A robotic hand controlled in real time by a webcam: Python reads hand
landmarks via OpenCV/MediaPipe and drives 5 servos through an Arduino.
